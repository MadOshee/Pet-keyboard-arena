## Часть 2: настоящие товары (нужен ты)

Покупки в Studio бесплатные и тестовые, но работают только для товаров, созданных в опубликованной игре.

1. Опубликуй место: File → Publish to Roblox.
2. Creator Hub (create.roblox.com) → твоя игра → Monetization:
   - **Passes**: VIP, Fast Hatch, 2x Coins.
   - **Developer Products**: Hatch Egg, Egg Reroll, Luck Potion, 1000 Coins, 5000 Coins, 15000 Coins.
3. Пришли мне id каждого товара (число в ссылке), я впишу их в `ShopConfig` и пришлю новую сборку.
4. Game Settings → Security → включи **Enable Studio Access to API Services**, иначе профиль не сохранится и покупка не подтвердится.

Мои предложения по ценам (поменяешь как хочешь): VIP 299, Fast Hatch 149, 2x Coins 199, Hatch Egg 25, Egg Reroll 15, Luck Potion 49, монеты 49 / 199 / 499.
