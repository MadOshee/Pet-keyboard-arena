# Этап 1: проверка в Studio

Сборка: вкладка Actions → последний зелёный запуск CI → Artifacts → `PetKeyboardArena-...` → распаковать → открыть `.rbxl` → Play.

| # | Что сделать | Что должно произойти |
|---|---|---|
| 1 | Нажать Play | Посередине клавиатура из клавиш с буквами, ты стоишь перед ней. Вверху таймер «Next round», внизу кнопка PLAY. В Output нет красных ошибок, есть строки `server started (6 services)` и `client started (2 controllers)` |
| 2 | Нажать PLAY | Кнопка становится зелёной READY |
| 3 | Дождаться конца таймера | Тебя переносит на край клавиатуры, вверху «Get ready» 3 секунды, ты не можешь двигаться, видно «Your team: RED» |
| 4 | Бегать по клавишам 60 секунд | Клавиши под тобой окрашиваются в цвет команды, полоска счёта и числа меняются |
| 5 | Конец раунда | Баннер «RED wins!», затем «Victory! +N coins», монеты справа вверху выросли. Через 5 секунд тебя возвращает к лобби |
| 6 | Не бегать весь раунд (стоять) | Баннер «Paint at least 3 keys...», монет нет, кнопка снова серая PLAY |
| 7 | Test → Clients and Servers → 2 игрока → Start, в обоих окнах нажать PLAY | Игроки попадают в разные команды, перекрашивают клавиши друг друга, у победителя 40+ монет, у проигравшего 20+ |
| 8 | Отжать кнопку READY перед концом таймера | В раунд тебя не берут |

## Сохранение (по желанию)

Пока место не опубликовано, Studio пишет в Output `data will not be saved` — это нормально, игра работает, но монеты не сохраняются между запусками.
Чтобы проверить сохранение: File → Publish to Roblox, затем Game Settings → Security → включить **Enable Studio Access to API Services**. После этого монеты должны остаться после выхода и нового Play.
